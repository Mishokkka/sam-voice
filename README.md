# SAM Voice 1.4.1

Модуль для Foundry VTT v13, позволяющий ведущему синтезировать речь через встроенный SAM или локальный Piper и синхронно воспроизводить её у ведущего и подключённых игроков.

## Требования

- Foundry VTT v13, проверено на build 351;
- socketlib;
- для Piper: локальный HTTP backend, по умолчанию `http://127.0.0.1:5050`.

## Что изменилось в 1.4.0

- `Play for All`, `/sam` и API теперь используют единый путь local + remote. Ведущий слышит ту же реплику, что и игроки.
- Каждый клиент повторно проверяет speech payload перед воспроизведением.
- Ошибки возвращаются в структурированном виде вместо молчаливого проглатывания.
- SAM ограничен 800 символами после транслитерации, Piper 1000 символами.
- Очередь ограничена 20 репликами.
- AudioContext должен реально перейти в `running`. Заблокированный клиент не начнёт неожиданно играть реплику позже.
- Диагностика клиентов имеет тайм-аут 4 секунды на клиента и не зависает из-за одного браузера.
- Piper проверяет MIME, сигнатуру и фактический размер аудио. Лимит transport payload составляет 4 МБ.
- Нелокальные backend URL заблокированы по умолчанию. Разрешение включается отдельно в Module Settings.
- SAM-синтез вынесен в Web Worker с безопасным fallback на основной поток.
- Добавлены request IDs, версия схемы запросов, миграции settings/profiles и ограниченный импорт профилей.

## Использование

Окно открывается кнопкой с роботом в панели чата. Кнопка автоматически восстанавливается после перерисовки Chat Log.

Горячие клавиши в поле текста:

- `Ctrl+Enter`: озвучить всем;
- `Alt+Enter`: локальный preview.

Игрок должен хотя бы один раз кликнуть или нажать клавишу внутри Foundry, чтобы браузер разрешил WebAudio. Статус виден в нижней панели Session Ready.

## API

Совместимый API:

```js
game.modules.get("sam-voice").api.open();
await game.modules.get("sam-voice").api.play("Текст реплики");
await game.modules.get("sam-voice").api.stop();
```

Версионированный API:

```js
const api = game.modules.get("sam-voice").api.v2;

await api.speak("Текст реплики");
await api.preview("Локальная проверка");
await api.stop();
await api.resetAudio();

console.log(api.getStatus());
console.log(await api.getClientStatuses());
```

`api.speak()` и `api.preview()` возвращают объект результата с `requestId`, локальным результатом, ответами клиентов и массивом `failures`.

Legacy chat command:

```text
/sam Текст реплики
```

## Silero (русский TTS на CPU)

Silero добавлен как третий движок, независимо от SAM и Piper. Нужен локальный Python HTTP-сервер (по умолчанию `http://127.0.0.1:5051`) и скачанная модель `v5_5_ru`. В интерфейсе выберите `Silero`, нажмите `Check` и укажите один из пяти голосов: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`.

Полная инструкция: [tools/silero/README.md](tools/silero/README.md). Веса модели не входят в модуль. На всех клиентах Foundry должна быть установлена обновлённая версия модуля; сервер синтеза запускается только у ведущего.

## Piper

Piper генерирует аудио на клиенте ведущего. Готовый файл передаётся игрокам через socketlib. Для длинных реплик предпочтительнее сжатый формат, если backend его поддерживает.

По умолчанию разрешены только loopback-хосты:

- `localhost`;
- `127.0.0.1`;
- `::1`.

Нелокальный сервер получает текст реплик. Включайте `SAM Voice: Allow remote TTS backends` только для доверенного адреса.

## Сборка

```bash
npm ci
npm run validate
npm run package
```

`npm run package` создаёт готовый ZIP в `releases/`.

Foundry загружает `dist/samvoice.js`. Worker SAM находится в `dist/assets/`; оба файла обязательны.
